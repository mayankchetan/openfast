## 2024-05-23 - Fortran OpenMP Offloading Pitfalls
**Learning:** `gfortran` OpenMP offloading is extremely sensitive to intrinsics (`matmul`, `transpose`) and external module procedures. Intrinsics often cause runtime crashes (Exit Code 8) due to missing device libraries. External procedures like `EqualRealNos` from libraries must be redefined locally and marked `!$OMP DECLARE TARGET` to work on device.
**Crucial:** Accessing module-level variables (like `Pi` from `NWTC_Library` or `fourpi` from the module itself) inside a `TARGET` region causes runtime crashes (SIGFPE or segfault) on `gfortran`.
**Action:** Always replace `matmul`/`transpose` with manual loops in offloaded kernels. Locally define helper functions and mark them `!$OMP DECLARE TARGET`. Redefine critical constants/parameters locally within device subroutines using `parameter` or local variables initialized with intrinsics (e.g., `acos(-1.0)` for Pi).
